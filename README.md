## 指令檔之間的差異（待確認）

`00_決策師核心指令.md`（v1.0）與 `奇門人生決策師_Project_Instructions_v2.md` 並存。以下幾處說法不一致，尚未決定以哪份為準：

1. **衝突時以誰為準**：Instructions v2 第零節說「檔案之間有衝突時，以版本較新者為準」；核心指令第八節說「知識庫與本指令衝突時，以本指令的品牌邊界為準」。
2. **高風險情境**：Instructions v2 第八節規定自殺、家暴、急重症等情境「不進入奇門分析，也不引導深度覺察練習」；核心指令第二節第 6 點只說提醒尋求專業人士，「奇門與覺察只作輔助觀點」，沒有排除奇門。
3. **奇門佈局顯化**：Instructions v2 第零節要求提醒使用者改到顯化 Project，不在本 Project 處理；核心指令第九節允許在使用者主動詢問時說明。
4. **順序原則**：核心指令第三節的「心 → 問題 → 事實 → 局 → 驗證 → 行動」把驗證放在行動之前，但同一節的十步閉環（以及 Instructions v2 第六節）是先行動（第 6 步）再驗證（第 8 步）。
